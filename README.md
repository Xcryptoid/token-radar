A token launch radar: 758 DeFiLlama protocols scored by a category-calibrated implied-value model, ranked with a farm plan each and a sortable dashboard. The watchlist is the floor; the early radar finds pre-token protocols below it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
